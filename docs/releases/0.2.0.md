## RL Studio 0.2.0 — première version

RL Studio est une application Windows pour **créer, partager et entraîner des projets d'apprentissage par renforcement**,
avec des environnements écrits en Python ou construits sur un **modèle Simulink** sans écrire de code.

### Points forts

- **Projets** : créer, dupliquer, renommer, supprimer (corbeille récupérable), un dossier par projet.
- **Simulink sans code** : choisissez dans un explorateur les signaux à observer et les paramètres à commander,
  écrivez la récompense en une expression ; l'état du modèle est conservé d'un pas à l'autre.
- **Entraînement** SAC / PPO / TD3 avec suivi en direct et comparaison à une politique de référence.
- **Partage en un fichier `.rls`** : export, import sécurisé, glisser-déposer, double-clic.
- **Installateur adaptatif** (à construire, voir ci-dessous) : détecte le GPU NVIDIA et MATLAB, installe la bonne
  version de PyTorch (`cu130` / `cu128` / `cu126` / CPU) et du `matlabengine` correspondant à votre MATLAB.
- **Thèmes** Sombre, Clair, Matrix et personnalisables ; réglages dans la fenêtre *Paramètres*.
- **Exemples génériques** : `python_blank`, `cartpole` (SAC : 499/500 en 30 000 pas), `simulink_blank`.

### Installer

L'installateur Windows n'est **pas joint** à cette release. Pour le construire (Python 3.12 et Inno Setup 6 requis) :

```powershell
git clone https://github.com/Toff1989/rl-studio.git
cd rl-studio
.\packaging\build.ps1      # produit dist-installer\RLStudio-Setup-0.2.0.exe
```

Ou, pour développer : `pip install -e ".[gui,runtime,dev]"` puis `rlstudio-gui` (voir le [README](../../README.md)).

### Compatibilité

- Windows 10/11 64 bits ; GPU NVIDIA facultatif ; MATLAB / Simulink facultatifs (licence de l'utilisateur).
- Testé avec MATLAB R2026b, Python 3.12, NVIDIA RTX 5080 (CUDA 13). Les autres configurations sont couvertes par des
  tests unitaires de planification, pas par des installations réelles.

### Sécurité

Un projet `.rls` contient du code qui s'exécute sur votre machine : l'import affiche la liste des fichiers de code et
demande confirmation, et refuse chemins dangereux, archives piégées et exécutables. N'importez que des projets de
confiance.

### Limites connues

- Installateur et exécutables **non signés** (avertissement SmartScreen).
- Windows uniquement ; Simulink : signaux de bus non supportés, un moteur MATLAB par environnement.
