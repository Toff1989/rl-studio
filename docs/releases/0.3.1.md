## RL Studio 0.3.1 — évaluation en direct et suivi de l'extraction

### Nouveautés

- **Onglet Évaluation** : rejoue un run entraîné (ou un modèle mathématique extrait) avec la politique déterministe et trace
  en direct les observations, les actions, la récompense cumulée et le retour par épisode. Choix du run, de la politique,
  du nombre d'épisodes, de la graine et de la vitesse ; arrêt possible à tout moment.
- **Entraînement** : observations et actions tracées en **courbes temporelles** nommées (une courbe par signal, légende),
  avec option de normalisation pour comparer des signaux d'échelles différentes.
- **Extraction du modèle mathématique** : progression fine (un pas par épisode simulé), étape en cours détaillée, temps
  écoulé et estimation du temps restant, journal visible pendant le calcul.

### Installer

L'installateur Windows n'est **pas joint** à cette release. Pour le construire (Python 3.12 et Inno Setup 6 requis) :

```powershell
git clone https://github.com/Toff1989/rl-studio.git
cd rl-studio
.\packaging\build.ps1      # produit dist-installer\RLStudio-Setup-0.3.1.exe
```

Ou, pour développer : `pip install -e ".[gui,runtime,dev]"` puis `rlstudio-gui` (voir le [README](../../README.md)).
