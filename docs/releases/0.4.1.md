## RL Studio 0.4.1 — aide intégrée, erreurs visibles, interface en français correct

Version centrée sur la prise en main : un néophyte doit pouvoir comprendre chaque choix sans documentation externe, et ne plus rater une erreur.

### Nouveautés

- **Une infobulle sur chaque élément** : boutons, champs, cases, listes, colonnes de tableaux, graphiques, onglets, assistants et Paramètres.
- **Guide d'utilisation intégré** : touche **F1**, bouton *Guide d'utilisation* de la barre latérale ou *Paramètres → Guide d'utilisation*. Sommaire, recherche, ouverture à la section de l'onglet affiché ; consultable même pendant un entraînement.
- **Les erreurs se voient** : un bandeau en haut de la fenêtre signale toute erreur, quel que soit l'onglet affiché, avec le détail complet et un bouton *Copier*. Avant, une erreur écrite dans un journal pouvait passer inaperçue.
- **Évaluation d'un modèle identifié** : l'onglet Évaluation rejoue un modèle de l'Identification à côté du vrai système, avec les mêmes actions. Ses courbes sont en pointillé, de la couleur du signal réel, et l'écart est chiffré par signal. Un nouveau pilote « paliers d'actions aléatoires » permet de comparer sans entraîner d'agent.
- **Français accentué** dans toute l'interface, les messages de calcul et les modèles de projet.
- **Identification en régime permanent plus robuste** : les signaux qui ne dépendent pas de l'entrée (horloge, occupation, météo, prix) sont repérés et écartés automatiquement des sorties à modéliser. Avant, des modèles comme *Ventilation CO2* échouaient avec « Trop peu de points stabilisés ». Vérifié sur tous les modèles Python fournis ; pour un système instable (pendule), le message d'erreur oriente vers le mode dynamique.

### En coulisses

- `gui/app.py` découpé en modules (un par onglet) : plus simple à maintenir, sans changement de comportement.
- Tests plus propres : les tests qui exigent PyTorch ou Qt sont ignorés (avec la raison) quand ces paquets manquent.
- Plage de Python explicite (3.10 à 3.12, 3.12 recommandé) avec avertissement hors plage.
- README complété (huit modèles de projet, commandes `distill` et `identify`).

### À savoir

- Le guide et les infobulles décrivent l'application telle qu'elle est ; si vous trouvez une explication peu claire, signalez-la.
- L'installateur n'est pas signé : Windows SmartScreen peut afficher un avertissement.

### Construire soi-même

Pour le construire (Python 3.12 et Inno Setup 6 requis) :

```powershell
git clone https://github.com/Toff1989/rl-studio.git
cd rl-studio
.\packaging\build.ps1      # produit dist-installer\RLStudio-Setup-0.4.1.exe
```

Ou, pour développer : `pip install -e ".[gui,runtime,dev]"` puis `rlstudio-gui` (voir le [README](../../README.md)).
