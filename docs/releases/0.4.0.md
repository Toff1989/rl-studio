## RL Studio 0.4.0 — identification d'un modèle réduit, sans politique

Un modèle Simulink (ou Python) tout prêt n'a pas besoin d'être appris : il suffit de le **balayer**. Le nouvel onglet **Identification**
remplace le modèle par des équations lisibles ou un réseau de neurones, validés sur des points jamais vus.

### Nouveautés

- **Régime permanent : entrées → sorties** (`y = f(u)`) : plan d'expérience en hypercube latin, chaque point simulé jusqu'à stabilisation,
  validation sur points neufs. Les non-linéarités fortes (saturations, valeurs absolues, produits sin × entrée) sont gérées par les
  équations parcimonieuses (SINDy) ou le réseau.
- **Dynamique** (`x(k+1) = x(k) + f(x, u)`) : paliers d'action aléatoires, validation en **simulation libre**, erreur par horizon, courbe d'apprentissage.
- **Quatre familles** : linéaire, polynôme, équations parcimonieuses, réseau de neurones ; recommandation du modèle le plus simple dans la tolérance.
- **Tout se règle** : entrées balayées ou fixées, plages, sorties, critères de stabilisation, nombres de points, hyperparamètres.
- **Exports** : Python, MATLAB et **bloc Simulink** (MATLAB Function, compatible génération de code).
- **Projets et `.rls`** : l'identification voyage avec le projet (réglages toujours inclus, résultats au choix) ; le code généré n'est pas embarqué
  et se régénère depuis `model.json`.
- **Nouveau projet fourni** : *Usine non linéaire (identification)*, dont l'identification retrouve exactement les formules.

Documentation : [docs/identification.md](../identification.md). En ligne de commande : `rlstudio identify <projet>` (`--mode dynamic` pour la dynamique).

### À savoir

- L'export vers Simulink demande MATLAB ; il n'a pas été exécuté sous MATLAB avant cette version (le code et la spécification générés sont testés).
- Le modèle n'est valable que dans les plages balayées ; un état caché dans le modèle Simulink se voit en mode dynamique (bon à un pas, mauvais en simulation libre).

### Installer

L'installateur Windows n'est **pas joint** à cette release. Pour le construire (Python 3.12 et Inno Setup 6 requis) :

```powershell
git clone https://github.com/Toff1989/rl-studio.git
cd rl-studio
.\packaging\build.ps1      # produit dist-installer\RLStudio-Setup-0.4.0.exe
```

Ou, pour développer : `pip install -e ".[gui,runtime,dev]"` puis `rlstudio-gui` (voir le [README](../../README.md)).
