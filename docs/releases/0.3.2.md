## RL Studio 0.3.2 — conversion de modèles Simulink, journal d'entraînement et arrêt immédiat

### Nouveautés

- **Convertir un modèle Simulink existant** : le bouton *Convertir un modèle Simulink…* (barre latérale, sous « Importer un projet ») ouvre
  une fenêtre en quatre étapes : analyse du modèle (entrées, sorties, constantes, solveur, variables manquantes, blocs d'affichage),
  choix des actions et des observations, variables initiales aléatoires, puis pas de décision et récompense. Le projet créé contient une
  **copie** adaptée du modèle — entrées → constantes pilotables, sorties → bloc source, affichages retirés, variables du workspace embarquées,
  solveur à pas fixe au choix — et un épisode court la teste à vide. Le fichier d'origine n'est jamais modifié.
- **Journal d'entraînement** horodaté à droite des graphiques : démarrage de MATLAB/Simulink, évaluation de référence épisode par épisode
  (barre de progression et temps restant), début de l'apprentissage, puis une ligne par épisode avec vitesse en pas/s et temps restant.

### Corrections

- **Bouton Arrêter** : il répond immédiatement (le process de calcul est tué avec MATLAB). Seul l'apprentissage en cours garde un arrêt
  propre de 3 secondes au plus pour enregistrer le modèle partiel. Un run interrompu avant l'enregistrement du modèle est supprimé et
  l'arrêt ne s'affiche plus comme une erreur.
- **Légende des graphiques temporels** avec beaucoup de signaux : une couleur distincte par signal, légende compacte dont les entrées sont
  cliquables pour masquer ou afficher une courbe.

### Installer

L'installateur Windows n'est **pas joint** à cette release. Pour le construire (Python 3.12 et Inno Setup 6 requis) :

```powershell
git clone https://github.com/Toff1989/rl-studio.git
cd rl-studio
.\packaging\build.ps1      # produit dist-installer\RLStudio-Setup-0.3.2.exe
```

Ou, pour développer : `pip install -e ".[gui,runtime,dev]"` puis `rlstudio-gui` (voir le [README](../../README.md)).
