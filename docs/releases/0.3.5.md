## RL Studio 0.3.5 — interface fluide pendant les calculs

### Corrections

- **Graphiques en direct** : l'ajout d'un point ne reconstruit plus toutes les courbes. Les dessins sont regroupés (≈ 25 par seconde au
  plus, moins sur les longs épisodes) et limités à ~1500 points par courbe en conservant les pics : l'interface ne ralentit plus quand
  un épisode s'allonge, en entraînement comme en évaluation rapide.
- **Journaux** bornés à 5000 lignes (entraînement, évaluation, extraction du modèle mathématique).
- **Bouton Arrêter** : `taskkill` s'exécute en arrière-plan, l'interface ne se fige plus jusqu'à 5 secondes.
- **Priorité** : le processus de calcul (PyTorch, MATLAB) tourne en priorité inférieure à la normale pour laisser la main à l'interface.
  Variable `RLSTUDIO_NORMAL_PRIORITY=1` pour revenir à la priorité normale.

### Installer

L'installateur Windows n'est **pas joint** à cette release. Pour le construire (Python 3.12 et Inno Setup 6 requis) :

```powershell
git clone https://github.com/Toff1989/rl-studio.git
cd rl-studio
.\packaging\build.ps1      # produit dist-installer\RLStudio-Setup-0.3.5.exe
```

Ou, pour développer : `pip install -e ".[gui,runtime,dev]"` puis `rlstudio-gui` (voir le [README](../../README.md)).
