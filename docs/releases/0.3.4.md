## RL Studio 0.3.4 — modèles polynomiaux et trois modèles de projet CVC

### Nouveautés

- **Modèle mathématique : famille Polynôme** (degrés 2 et 3 par défaut, termes croisés inclus, régression régularisée sur les observations
  normalisées). Équations lisibles, export Python / MATLAB / Simulink, sauvegarde JSON, option CLI `--methods polynomial`.
- **Trois modèles de projet CVC / bâtiment**, en Python autonome (sans simulateur externe) et avec un régulateur de référence :
  - *PAC air/eau – régulation d'une zone* : modèle thermique RC (air + masse), COP et capacité selon la météo, consigne jour/nuit ;
  - *Ventilation à la demande (CO₂)* : occupation variable, coût du ventilateur et du chauffage de l'air neuf ;
  - *Ballon d'ECS – tarif et photovoltaïque* : heures pleines/creuses, production PV, soutirages aléatoires.

### Installer

L'installateur Windows n'est **pas joint** à cette release. Pour le construire (Python 3.12 et Inno Setup 6 requis) :

```powershell
git clone https://github.com/Toff1989/rl-studio.git
cd rl-studio
.\packaging\build.ps1      # produit dist-installer\RLStudio-Setup-0.3.4.exe
```

Ou, pour développer : `pip install -e ".[gui,runtime,dev]"` puis `rlstudio-gui` (voir le [README](../../README.md)).
