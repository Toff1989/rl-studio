## RL Studio 0.3.0 — extraire l'intelligence de l'agent

Un agent entraîné par RL est un réseau de neurones opaque. Cette version en extrait une **loi de commande lisible**,
validée en simulation et exportable vers Python, MATLAB et Simulink.

### Points forts

- **Onglet « Modèle mathématique »** et commande `rlstudio distill <projet>` : régulateur **linéaire / PID** (action
  intégrale optionnelle), **table de gains**, **arbre de décision**, **équation symbolique** parcimonieuse, ou **copie
  exacte du réseau** (vérifiée numériquement). SAC, PPO et TD3.
- **DAgger** contre la dérive de distribution, **validation en boucle fermée** (score normalisé, R², complexité, épisodes
  menés à terme) et **recommandation du modèle le plus simple** qui reste dans la tolérance.
- **Exports** `policy.py`, `policy.m`, `equations.txt` et **contrôleur Simulink** (bloc *MATLAB Function*) ; le code
  MATLAB et le modèle Simulink générés sont comparés à Python dans les tests.
- Garde-fous : action déterministe, écrêtage aux bornes, alerte de saturation, extrapolation, modèles à état.
- **Template `cartpole_simulink`** (modèle MIT adapté), **lanceur `lancer.bat`**, nouvelle icône, lecture tolérante au BOM UTF-8.

Sur le CartPole fourni (SAC 30 000 pas, retour 332), une équation à 3 termes ou un PID à 5 paramètres reproduisent
(et même lissent) le comportement de l'agent. Détails : [docs/distillation.md](../distillation.md).

### Installer

L'installateur Windows n'est **pas joint** à cette release. Pour le construire (Python 3.12 et Inno Setup 6 requis) :

```powershell
git clone https://github.com/Toff1989/rl-studio.git
cd rl-studio
.\packaging\build.ps1      # produit dist-installer\RLStudio-Setup-0.3.0.exe
```

Ou, pour développer : `pip install -e ".[gui,runtime,dev]"` puis `rlstudio-gui` (voir le [README](../../README.md)).

### Compatibilité et limites

- Windows 10/11 64 bits ; GPU NVIDIA, MATLAB et Simulink facultatifs (export Simulink : MATLAB requis).
- Actions continues (`Box`) uniquement pour l'extraction ; aucune garantie formelle de stabilité (le rapport mesure la
  proportion d'épisodes menés à terme). Installateur non signé (avertissement SmartScreen).
- Testé avec MATLAB R2026b, Python 3.12, NVIDIA RTX 5080 (CUDA 13).
