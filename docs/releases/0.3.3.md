## RL Studio 0.3.3 — installation fiabilisée sur les postes restreints

### Corrections

- **Installation des composants de calcul** : pip ne bascule plus en installation « --user » (erreur « User site-packages are disabled
  for this Python »). `Lib\site-packages` est créé d'avance et l'environnement de pip est isolé (variables `PIP_*` supprimées,
  `PIP_USER=0`, configuration pip ignorée).
- **Construction de l'installateur** : configuration pip de la machine écartée, erreur réelle de pip affichée, nettoyage robuste de
  `dist` et `build` (arrêt des instances en cours, réessais, message clair si OneDrive ou l'antivirus verrouille un dossier).

### Installer

L'installateur Windows n'est **pas joint** à cette release. Pour le construire (Python 3.12 et Inno Setup 6 requis) :

```powershell
git clone https://github.com/Toff1989/rl-studio.git
cd rl-studio
.\packaging\build.ps1      # produit dist-installer\RLStudio-Setup-0.3.3.exe
```

Ou, pour développer : `pip install -e ".[gui,runtime,dev]"` puis `rlstudio-gui` (voir le [README](../../README.md)).
